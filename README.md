# Orbit

소중한 사람들과 어떻게 연락하고 지내는지 기록하는 개인 관계 관리 앱입니다.

## 열어보기

`index.html`을 웹 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 화면 구성

- **왼쪽:** 카테고리 (모든 사람, 친구, 동료 등). 새 카테고리를 추가할 수 있습니다.
- **위쪽 카드 세 장:** 누르면 해당하는 사람만 목록에 보입니다.
  - **관심 필요:** 마지막 연락이 30–89일 전
  - **연락 끊김:** 90일 넘게 연락이 없거나 기록 없음
  - **이번 주 후속 연락:** 다음 연락 예정일이 이번 주 일요일까지 (지난 날짜 포함)
- **가운데:** 이름 목록. 이름, 회사, 마지막 연락 시점, 최근 기록이 보입니다.
- **오른쪽:** 프로필. 이름·회사·카테고리·다음 연락 예정일을 바로 고칠 수 있고, 연락할 때마다 기록을 한 줄씩 남깁니다.

휴대폰에서는 한 줄로 쌓이고, 이름을 누르면 프로필이 화면 위로 열립니다.

## 데이터

- 처음에는 예시 인물 10명이 보입니다. 실제 사람이 아닙니다. 왼쪽 아래의 **예시 지우고 시작하기**로 지울 수 있습니다.
- 입력한 내용은 지금 쓰는 브라우저에 저장됩니다. 다른 기기나 다른 브라우저와는 공유되지 않습니다.

## 파일

- `index.html` — 페이지
- `styles.css` — 디자인
- `app.js` — 동작
- `sample-data.js` — 예시 인물

## 아이폰에 설치하기

1. 아이폰 **Safari**에서 Orbit 주소를 엽니다.
2. 아래쪽 공유 버튼 → 목록을 아래로 내려 **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 Orbit 아이콘으로 열면 전체 화면으로 뜨고, 인터넷 없이도 열립니다.

주소는 GitHub Pages로 자동으로 올라갑니다 (`.github/workflows/pages.yml`).
